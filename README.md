# Fenegram

Fenegram - урезанный мессенджер с одним общим текстовым и голосовым каналом.

Название собрано из первых букв игровых ников создателей. Текстовый канал работает через Photon Realtime, голосовой - через LiveKit Cloud.

## Возможности

- один главный текстовый канал;
- один голосовой канал;
- текст через Photon Cloud и голос через LiveKit Cloud;
- выбор микрофона и наушников/динамиков;
- общая громкость, громкость микрофона и отдельных участников;
- зеленый индикатор, когда пользователь говорит;
- Windows-приложение и адаптивная веб-версия для телефонов.

## Windows-приложение

Готовый файл:

```text
dist\Fenegram.exe
```

Он сам запускает локальную часть и открывает отдельное окно через Edge, Chrome или Opera.

После запуска рядом с часами появляется иконка `FG`.

Через нее можно:

- открыть новое окно Fenegram;
- запустить серверную часть после остановки;
- остановить все окна и локальную часть;
- полностью выйти из приложения.

Для новой сборки:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_app.ps1
```

## Локальный запуск веб-версии

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Откроется `http://127.0.0.1:4173`.

## Телефоны

Чтобы Fenegram работал на телефоне, файлы `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` и папку `lib` нужно опубликовать на HTTPS-хостинге.

Подойдут GitHub Pages, Cloudflare Pages, Netlify или Vercel.

HTTPS обязателен: мобильные браузеры обычно не разрешают микрофон на обычной HTTP-странице.

После публикации:

1. Открой HTTPS-ссылку на телефоне.
2. Нажми `Подключиться`.
3. Нажми `Войти в голос`.
4. Разреши браузеру доступ к микрофону.
5. При желании добавь сайт на главный экран телефона.

## Архитектура

- Photon Realtime хранит общий канал и доставляет текст.
- LiveKit Cloud передает голос, помогает участникам соединяться из разных сетей и определяет, кто говорит.
- В проекте используется sandbox token server LiveKit. Он подходит для тестирования с друзьями, но перед публичным запуском его нужно заменить собственным сервером выдачи токенов.
