Photon Voice JavaScript SDK is required for Photon Voice calls.

Download from Photon while signed in:
https://www.photonengine.com/sdks

Choose:
Voice -> JavaScript -> JavaScript version 4.4

From the downloaded archive, copy:
lib/Photon-Javascript_SDK.js

Into this folder as:
photon-voice-javascript-sdk.js
